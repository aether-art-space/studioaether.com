# Aether 셀프사진관 이용 안내

## 촬영 전

1. 원하는 배경과 조명 스타일을 직원과 함께 선택해 주세요.
2. 카메라 앞에서 화면을 보며 위치와 구도를 확인해 주세요.
3. 궁금한 점이 있으면 언제든지 직원에게 말씀해 주세요. 직원은 한국어를 구사하지 않지만, 번역 앱이나 영어로 기꺼이 도와드립니다.

## 촬영하기

1. 준비가 되면 리모컨의 셔터 버튼을 눌러 주세요.
2. 버튼을 누른 뒤 2초 후에 사진이 촬영됩니다. 그동안 리모컨을 손에 감출 수 있습니다.
3. 화면에서 사진을 확인하고 원하는 만큼 촬영해 보세요.
4. 도움이 필요하거나 배경과 조명을 바꾸고 싶으면 직원에게 말씀해 주세요.

## 촬영 후

- 촬영한 사진 전체를 온라인으로 전달해 드립니다.
- 사진 보정은 별도 유료 서비스입니다. 원하시면 직원에게 문의해 주세요.
- 예약 시간에는 촬영 준비와 정리 시간이 포함됩니다. 사용한 공간을 처음 상태로 정리해 주세요.
- 변경 및 취소는 이메일 또는 전화로 문의해 주세요.
